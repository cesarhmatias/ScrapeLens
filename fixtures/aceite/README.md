# fixtures/aceite — sintéticas

Geradas por `tests/aceite/fixtures.py`. Todos os domínios usam `.invalid`, os
horários são fixos e os dados são inventados. Cada diretório tem `fixture.json`
com `label: synthetic-fixture`.

Nenhuma fixture contém tráfego real, cookie real ou credencial válida. Os
segredos de `sanitize/` são marcadores (`SECRET-*`) usados para provar que a
sanitização os remove.
